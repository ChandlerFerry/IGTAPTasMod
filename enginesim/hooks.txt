# Calls the retarget step injects into game methods, mirroring the plugin's Harmony patches (TasPlugin.Awake).
# prefix  <Type::method> <IGTAP.EngineSim.Hooks method>   call the hook with (this, args...) first
# replace <Type::method> <IGTAP.EngineSim.Hooks method>   the method becomes just that call
prefix Movement::getPlayerControlledInput OnPlayerInput
# MacroEngine.WallTouch: a dash that hits a wall takes its input tick after all; its presses go in before the wall
# branch reads the buttons.
prefix Movement::touchedSolidGround OnWallTouch
prefix Movement::touchedMossyGround OnWallTouch
prefix Movement::onDeath OnDeath
# TasPlugin.BeforeRespawn: a death respawns at a checkpoint only with the studio's "Checkpoint respawns" on.
prefix Movement::respawn OnRespawn
# The plugin reads the course time before stopTracking and ends the run after it; everything else stopTracking
# does is rewards and UI. The host hook applies its two state changes (tracking off, courseResetPoint cleared).
replace courseScript::stopTracking OnCourseStop
# A box buys on a trigger stay when its cooldown is up, the player can afford it and it is active. The host hook applies
# that rule and what a purchase changes that a run can observe (Cash, cost, cap, unlocks, the segment's finish), not the
# boxes' UI, particles or save bookkeeping.
replace upgradeBox::OnTriggerStay2D OnUpgradeBoxStay
# The clones' LoD trigger (clonesLoD) tells a course's clones whether the player is near: on screen they walk the path
# and pay at its end, off screen they pay at once. The host economy keeps the clones (Economy.OnScreen).
replace clonesScript::isOnScreen OnClonesOnScreen
# A course's reward from the upgrades; fullUpdate is that plus UI. The host economy computes it (a no-op without it).
replace courseScript::UpdateReward OnCourseReward
replace courseScript::fullUpdate OnCourseReward
# Sound draws UnityEngine.Random (a clip, a pitch) on every turbo tick the player makes a sound on. cuts.txt empties
# these two; the hooks keep exactly the draws the game's bodies make (see enginesim/README.md's consumer audit).
# playSFX also draws for the Audio.PlayAudio its land cases make (the body is empty here, so the hook draws those too).
prefix Movement::playSFX OnPlaySfx
prefix Audio::PlayAudio OnPlayAudio
# PlayAudioAtPoint (a zip mover's end boom) draws the same way.
prefix Audio::PlayAudioAtPoint OnPlayAudioAtPoint
# Block swap on dash: Movement calls the swapper directly, not through a physics callback, so the host marks it touched
# (Simulation.Touch) and a restore puts isBlueActive back. The colliders it toggles are tracked by Engine.EnabledChanging.
prefix colouredBlockSwapper::swapBlocks OnSwapBlocks
# The dash's freeze (TimeStop, cut) stops physics while Update keeps running every rendered frame. The hook reports the
# call so the host runs the freeze's Update frames (Simulation.InterpolatedFrames, MacroEngine.FrameGrid.FrozenFrames).
prefix Movement::TimeStop OnTimeStop
# A refill orb's refresh sets whether it is usable (its cooldown is over and the refill upgrades reach its
# ActivationSequence) and its sprites. The host hook sets the flag (Simulation.RefillOrbState), not the sprites.
replace JiggleDropScript::SetActiveVisualState OnRefillOrbState
# The tech contacts (Runtime\TechGrafts.cs ContactLog.Step): a spring hit with the spring's up, and a special wall jump
# (a wallbounce, a dash into a wall with the jump buffered, a dash-boosted wall jump). Observers only: the game's bodies
# run unchanged.
prefix Movement::hitSpring OnHitSpring
prefix Movement::SpecialWallJump OnSpecialWallJump
# The step-up's animation call (Movement.Update lifting the player onto a step; its body is cut): the step-up contact.
prefix StepUpAnimationScript::onSteppedUp OnSteppedUp
# The tech checks (Runtime\TechSteps.cs, the overlay's detectors offline): CheckForSuperJump's state before it runs,
# determineSpriteDirection (the call right after getPlayerControlledInput) for the state the input left, and a zip
# mover made intangible (a jump touching it). Observers only.
prefix Movement::CheckForSuperJump OnCheckForSuperJump
prefix Movement::determineSpriteDirection OnDetermineSpriteDirection
prefix PlatformMover::MakeIntangible OnMakeIntangible
# AtomColliderSystem's 0.4 s grid (OnEnable's InvokeRepeating) lands a waiting atom: the host economy keeps the atoms
# (Economy.AtomTick), the counts on globalStats.
replace AtomColliderSystem::callAddNewAtom OnAtomTick
