# Full-TAS v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Full-TAS solver with one command that builds plans exactly from reusable segments, owns its waits,
and is protected by a pre-commit check, then improve ZipEscape% with it.

**Architecture:** A new module `enginesim/Cli/Runs/` (namespace `IGTAP.EngineSim.Cli.Runs`) on top of the unchanged engine
(`Simulation`, `OfflineSolver`, `SnapshotStore`, `FullTasTracker`). A plan is the run's goal list; the builder plays it
step by step from a segment library (replayed, never trusted) or a deterministic search, recording waits; the improver
edits economy steps and keeps edits that make the built route faster. `check` replays the complete runs and the trace
corpus against committed baselines; a git hook runs it before engine commits.

**Tech Stack:** C# / .NET 10 (`enginesim`), BepInEx plugin (C#, Newtonsoft.Json), Next.js studio (`web/`), Python 3
tools, git hooks.

**Spec:** `docs/superpowers/specs/2026-10-09-fulltas-v2-design.md`

## Global Constraints

- README `### Rules` 1-54 and exceptions 1-13 hold unchanged; the gate (`/api/fulltas/submit`, `SaveSolverRoute`) is unchanged.
- No write to game state to make a join exact: every join is inputs only.
- Search offline in `enginesim` (rule 45); the game only captures traces, confirms bests, runs checks (rule 46).
- Budgets are simulated ticks, never wall-clock; searches use fixed seeds (`rng = 1 + i`), one worker per solver.
- One `Simulation` per thread (`Solve.OnThread` / `Solve.Workers`); a `SimSnapshot` never crosses Simulations (use
  `SnapshotStore` bytes, or replay the prefix).
- Long engine runs use a private build: `dotnet build enginesim/Cli/IGTAP.EngineSim.csproj -c Release -o <dir>`.
- Stop only our own engine processes, by PID.
- Code style: the surrounding code's (file-scoped `sealed class`, doc comments that say why, invariant culture).
- Commit after every task (`Co-Authored-By: Claude <noreply@anthropic.com>`), on branch `solver-v2`, worktree
  `C:\Users\deafwave\Downloads\IGTAP\wt-solver-v2`.
- Paths: `$CFG` = `C:\Program Files (x86)\Steam\steamapps\common\IGTAP an Incremental Game That's Also a Platformer\BepInEx\config\IGTAPTasMod\enginesim`
  (traces `$CFG\fulltas-<run>.json`, bests `$CFG\fulltas\<run>.json`).

## Review Focus

1. A run whose saved best is shorter than its goals (Zip% reaches 807 of 1492): `check` records it as it is and fails
   only on change; the builder starts from the goals it reaches and builds the rest.
2. A buy whose box isn't active yet (a tree box still growing, Need() null): the builder waits for it like a short
   currency, and fails with `no-income` only when nothing changes.
3. A segment that reaches its goal only in ticks after its last input (dash ticks, a fall): 20 explicit idle inputs are
   appended before replay so the cut never relies on inputs that ran out.
4. Two quick restarts on consecutive ticks (refused by the gate): a segment starting with `reset` after a step that
   ended on `reset` is never played; the builder inserts no such pair.
5. A trace or best file missing for a `complete` run, or a run file in the old format (VMAN: `held` -1, no `live`):
   `check` reports it and compares what exists, it doesn't crash.

- [ ] **Step 1: Write the hook.**

```bash
#!/usr/bin/env bash
# Runs the engine check before a commit that touches what the engine compiles (enginesim/, runs/, the shared root sources).
set -e
files=$(git diff --cached --name-only)
echo "$files" | grep -qE '^(enginesim/|runs/|MacroEngine\.cs|MacroModels\.cs|FieldState\.cs|FullTas\.cs|Categories\.cs|CourseStart\.cs|WokenStarts\.cs)' || exit 0
[ -n "$IGTAP_SKIP_CHECK" ] && { echo "pre-commit: check skipped (IGTAP_SKIP_CHECK)"; exit 0; }
root=$(git rev-parse --show-toplevel)
tmp=$(mktemp -d)
git checkout-index -a --prefix="$tmp/src/"
out="$tmp/bin"
dotnet build "$tmp/src/enginesim/Cli/IGTAP.EngineSim.csproj" -c Release -o "$out" -v q -nologo 2>&1 | tail -3
"$out/IGTAP.EngineSim.exe" check --repo "$tmp/src" || { echo "pre-commit: check failed (an intended change: run check --accept and commit the baselines)"; exit 1; }
rm -rf "$tmp"
```

`git checkout-index` writes the staged tree, so the check judges what is committed, not the working tree.

### Task 8: The builder

**Files:**
- Create: `enginesim/Cli/Runs/Builder.cs`

**Interfaces:**
- Consumes: Tasks 5-7.
- Produces:
  ```csharp
  sealed class Wait { public int Goal; public string Label; public float X, Y; public long Ticks; public string Currency;
      public double Short, PerTick; }
  sealed class Failure { public string Kind; public int Goal; public string Label; public string Text; public string Key; }
  sealed class Built {
      public Plan Plan; public List<InputTick> Inputs = new(); public List<int> StepEnd = new(); public List<SimSnapshot> States = new();
      public List<long> Physics = new(), Held = new(); public List<Wait> Waits = new(); public Failure Failure;
      public int Reached => StepEnd.Count; public bool Complete => Reached == Plan.Count;
      public double Live => Reached == 0 ? 0 : MacroEngine.LiveSeconds(Physics[^1], Held[^1]);
  }
  sealed class Builder {   // one per thread: owns its Simulation
      public Builder(RunContext run, SegmentLibrary lib, SegmentSearch search, bool searchMisses);
      public Built Build(Plan plan, Built reuse = null);   // reuses reuse's steps while the plans agree
      public List<(int goal, byte[] state, List<InputTick> prefix)> Misses;   // when searchMisses is false
  }
  ```
  Step build (goal j): state `S` = `States[j-1]` (origin for 0). Unlocks from `Movement` (as `FullTas.Unlocks`).
  1. **Play**: for each library candidate (`Candidates(label, unlocks, x, y, phase, facing)`): inputs + 20 idle inputs;
     `sim.SetStart(S.WithGoal(progress j), StepEnd[j-1])`, `AdvanceToGoal(inputs, j + 1, out consumed)`; valid when
     non-null; keep the one with the lowest goal physics tick. Never play a candidate starting with `reset` right after
     a step whose last input is `reset`.
  2. **Wait** (buy/reward goals whose boxes aren't `Affordable == true` at S): idle from S in chunks of 500 ticks until
     affordable (A ticks). The currency not rising for 3 chunks with the box active, or the box inactive for 20 chunks,
     or A > 60,000: `Failure{Kind="no-income"}`. Then the walk: candidates (and a search if none) from the state after A
     idle ticks; the wait k = the fewest idle ticks in [0, A] (binary search, then a scan of the 5 below) after which
     the walk still buys; the step's inputs are k idle ticks plus the walk; record `Wait{Ticks=k, Short=need-holds at S,
     PerTick=(holds after k - holds at S)/k}`.
  3. **Search** when no candidate plays: `SegmentFacts` key `to|unlocks|x,y rounded to 16|phase|engine`; skipped when
     failed with this budget; else `Find(...)` (20,000,000 ticks; a retry 4x up to 320,000,000) seeded with the 8 nearest
     candidates' inputs; each find validated as in 1; the best filed in the library (`Source="search"`). With
     `searchMisses` false the miss is recorded in `Misses` and the build stops there (`Failure{Kind="miss"}`).
  4. **Unreachable**: search found nothing: `Failure{Kind="unreachable", Text="no way from (x, y) to <label> with
     <unlocks> after N ticks: add an avoid box or a waypoint (at:) here"}`.
  5. Append, store the state and the goal's physics and held ticks.

## Phase 3: the improver and the command

### Task 9: The improver

**Files:**
- Create: `enginesim/Cli/Runs/Improver.cs`

**Interfaces:**
- Consumes: Builder, Plan, Wait.
- Produces:
  ```csharp
  sealed class Improver {
      public Improver(RunContext run, SegmentLibrary lib, SegmentSearch search, int threads);
      public Built Best { get; }
      public event Action<Built, string> NewBest;            // (best, move description)
      public event Action<object> Event;                       // @fulltas events: plan, waits, failure, status
      public void Run(Plan start, Func<bool> stop);           // until converged or stop()
  }
  ```
  Moves from the current best (fixed order): for each wait, longest first: insert `farm:N`/`record:N` before it for each
  lap course seen in the run's goals or the header (record when the run hasn't lapped N since its last different
