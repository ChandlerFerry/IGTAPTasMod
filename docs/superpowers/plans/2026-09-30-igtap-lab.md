# igtap-lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Recharge mod, `ChandlerFerry/igtap-lab`, that builds all 70 IGTAP tech labs on one map with a bounding box
around each, a ghost of each demo, and an input tracker on every lab demo.

**Architecture:** `tools/pack.py` turns IGTAPTasMod's `labmaps/` into one packed `labs/world.json`, with each ghost path
rewritten offline by `IGTAP.EngineSim lab replay --write-path` at its packed anchor. The C# mod reads it. `LabWorld`
builds the colliders, outlines and labels. `LabSession` moves the player in and out and keeps saves off through the
game's own `courseResetPoint` check. `LabOverlay` draws the ghost and the tracker.

**Tech Stack:** C# netstandard2.1 against the game's `Managed` DLLs and `Recharge.ModApi.dll`; Newtonsoft.Json (ships
with the game); Python 3 for the pack tool; `IGTAP.EngineSim.exe` (IGTAPTasMod) for the offline replays.

**Spec:** `docs/superpowers/specs/2026-09-30-igtap-lab-design.md` (IGTAPTasMod).

## Review Focus

1. Leaving the lab (the Exit row, a scene change, or unloading) must restore every unlock field, the position, the
   velocity, `courseResetPoint` and `respawnPoint`. A missed one corrupts the player's next save.
2. FloatingOrigin rebases move the world. Lab roots, outlines and the ghost must stay registered with the terrain after
   a rebase, and the box check must use the current origin.
3. Death on a lab spike respawns at the demo's start (`respawnPoint`), not at a course checkpoint.
4. A demo without a `path` has no ghost, and its tracker still works.
5. A lab whose box is taller than the screen: labels stay readable and the outline stays visible (a line width in world
   units, scaled to the lab).

### Task 1: Pack tool and world.json

**Files:** Create `tools/pack.py`, `labs/world.json`.

**Interfaces:** Produces `labs/world.json` matching `src/Model.cs` exactly: `{labs: [{id, name, tech, category, anchor,
box, shapes, start, hand, finish, demos: [{name, start, category, inputs, path}]}]}`. `box` = `[x, y, w, h]` with a
lower-left corner, anchor-relative. `demos[0]` is the lab's main demo (`name` ""). `demo.start` = the demo file's
`start` if it has one, else the lab's `start`. `demo.category` = the demo file's `requires` if any, else the lab's
`category`.

- [ ] **Step 1:** Write `bounds(lab)` in `tools/pack.py`. It covers every box shape (rotated corners when `rotation`),

- [ ] **Step 2:** Pack: sort by height, descending, and fill rows up to a 20000 u row width with a 300 u gap. The result
  is each lab's offset inside the pack and the pack's total W × H.

  Take the first region it lists. Each lab's new anchor is that region's corner plus its offset, minus its bounds'

- [ ] **Step 4:** Write ghost paths. For each demo (the lab's `<id>.demo.json` and each `<id>.<name>.demo.json`), copy
  the lab JSON with the new `anchor` and the demo into a temp dir. Run `lab replay <its solvedIn trace> <tmp lab> <tmp

  into world.json with `path: null`. Round path numbers to 2 decimals.
- [ ] **Step 5:** `--check` asserts that no two boxes overlap (placed at their anchors) and that every shape, start and

### Task 3: Ghost and input tracker

**Files:** Replace `src/LabOverlay.cs` (and add `src/LabGhost.cs` and `src/LabTracker.cs` if that reads better).

**Interfaces:** Consumes the `LabSession` API above (stubbed now; code against the signatures). Produces the
`LabOverlay : MonoBehaviour` that draws only while `LabSession.Current != null`.

- [ ] **Step 1: Ghost.** Port IGTAPTasMod `LabGhost.cs` (312 lines) down to one ghost: the selected demo's `path`,
  anchor-relative through `LabSession.LabToScene`. It advances one entry per physics tick from `AttemptStarted`,
  interpolated per frame, holds the last point for 25 ticks, then loops. It's a flat-colour silhouette of the player's
  sprite, cyan at 0.65 alpha. There's no ghost when `path` is null.
- [ ] **Step 2: Chips.** A pure `static List<Chip> Chips(List<InputTick> inputs)` (no Unity calls, so a check can run
  it) makes one chip per change against the previous tick:
  - the stick direction, quantised to 8 directions or neutral, labelled with an arrow;
  - `press` → jump;
  - `release` → jump release;
  - `dash` → dash, with its `turnX`/`turnY` as a separate "turn" chip on the same tick;
  - `pause > 0` → pause.

  `Chip { int Tick; string Kind; string Label; }`. Add `tools/chips-check.csx`, or a `--check` in a tiny console
  project under `tools/`, that asserts the chips of a hand-written 6-tick input list. Pick whichever runs without the
  game, and keep it small.
- [ ] **Step 3: Live input.** Per physics tick (`FixedUpdate` on the overlay, counted from `AttemptStarted`), read the
  player's input:
  - the stick from `Movement.MoveAxis`;
  - jump and dash presses and releases from the `Movement` fields `jumpAction` and `dashAction` (`InputAction`,
    reflection), accumulated per frame in `Update` so a press between ticks isn't lost;
  - the pause from `player.pauseMenu.menuOpen` rising.

  Turn them into the same chip kinds with their ticks.
- [ ] **Step 4: Match and draw.** For each demo chip, the nearest live chip of the same kind not yet used:
  - same tick → green;
  - 1–3 ticks off → amber, labelled "+2" / "−1";
  - otherwise, or never → red, shown once the attempt is 4 ticks past the chip.

  The panel sits at the top centre, styled like IGTAPTasMod `LabTrainer.cs` `DrawLabTrainer`/`DrawChips`/
  `DrawTrainerTimeline`. It shows:
  - a title with the lab and demo name, and successes / attempts;
  - the chips with the player's bound keys (`InputAction.GetBindingDisplayString()`, as `Keys()` there);
  - one message: the first miss, or "finish!";
  - a timeline over the demo's tick span, with the demo's marks, the player's marks and a cursor.

  An attempt ends at `InFinish()` (a success) or at the next `AttemptStarted`.
- [ ] **Step 5:** Build: 0 errors, 0 warnings. Run the chips check. Commit with the message "Ghost and input tracker for
  every lab demo".
